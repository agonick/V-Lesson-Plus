# V-Lesson Plus (Uninettuno Chrome Extension)

This project is a Chrome Extension designed for students of Uninettuno University to enhance their video lesson experience.

## Architecture & Tech Stack
- **Language**: TypeScript (`src/*.ts`)
- **Build System**: `esbuild` for bundling into the `dist/` directory
- **Testing**: `vitest` for unit tests (`test/` directory)
- **Permissions**: `activeTab` and `storage` (uses `chrome.storage` API)
- **Core Files**:
  - `src/content.ts`: Injected into `https://www.uninettunouniversity.net/*` to interact with the DOM and video player.
  - `src/logic.ts`: Core business logic decoupled from DOM for testability.
  - `src/popup.ts`: Logic for the extension's popup UI (`popup.html`).

## Principal Functions (Features)
The extension currently has 3 main features:
1. **Speed Rate**: Manages the playback speed rate of the HTML5 video player in Uninettuno lessons.
2. **Autoplay**: Automatically clicks/advances to the next lesson when a video ends (if a next lesson is available in the DOM).
3. **Markers**: Provides the ability to save custom timestamps (markers) in video lessons, likely stored using `chrome.storage`, so students can quickly jump back to important parts.

## Agent Instructions & Rules
1. **TypeScript First**: Always write new code in TypeScript (`src/`) and ensure types are strictly defined. Never edit the files in `dist/` directly, as they are generated by `esbuild`.
2. **Build Process**: If you modify `.ts` files and want to test changes, remember that `npm run build` (or `npm run build:watch`) must be executed to transpile to `dist/`.
3. **DOM Independence**: Keep complex business logic in `logic.ts` where it can be unit tested with `vitest` via `npm test`, keeping `content.ts` focused purely on DOM manipulation.
4. **Manifest V3**: Adhere strictly to Chrome Extension Manifest V3 security and architecture policies.
